    Datagora

    datagora.mx

    Datagora es el laboratorio de inteligencia artificial que estoy construyendo. Desarrollamos la infraestructura para poner agentes a trabajar y diseñamos pruebas para entender cómo se comportan. Quiero que ese trabajo nos dé más tiempo y atención para aprender, crear y cuidarnos.

    Colme

    Motor de orquestación para agentes de IA

    Colme es el motor que ejecuta los flujos de un agente. Coordina qué modelo se usa, qué contexto recibe y qué herramientas puede llamar. Cada producto define sus propios flujos y reutiliza la misma capa de ejecución.

    87.64 % en Terminal-Bench 2.1

    Data Gateway

    Dale a tus agentes acceso a los datos que ya usas. Data Gateway convierte bases de datos, catálogos de Shopify y archivos CSV en herramientas de consulta. Puedes comprobar qué devuelve cada consulta antes de habilitarla.

    Ver el repositorio de Data Gateway

    Safety Research

    Diseñamos pruebas para evaluar en qué decisiones de un agente puede confiar un equipo. Revisamos los pasos que llevan al resultado para detectar fallos y medir cuándo la intervención humana ayuda a evitarlos.
